# Media guide (for the person adding multimedia)

You only edit **one file per question** in `js/branches/`. You never need to touch the engine (`js/core/`).

## 1. See what's still missing

Open the site with `?dev` at the end of the address:

```
index.html?dev
```

- Click **📋 Checklist** (top right). Every node is listed with ✓ (done), ✗ (missing image) and 📌 (media still needed).
- Inside panels, yellow **📌 Media needed** boxes show the teammate's original multimedia cue plus tips.
- ⚠ boxes under references show what still needs checking.
- These boxes never appear without `?dev`, so the marker never sees them.
- Add `&nointro` to skip the intro while testing: `index.html?dev&nointro`

## 2. Where media goes

Every node has a `detail.media` list. Each item has a `type` and an `at` position:

| `at` | Shows up |
|---|---|
| `"top"` | Above the hook (default for images) |
| `"hook"` | Right after the hook, before the argument |
| `"end"` | After the argument (default for video/audio/interactive) |

```js
detail: {
  hook: "...",
  argument: { label: "Core argument & IE connection", html: "<p>...</p>" },
  media: [
    { type: "image",   src: "images/my-pic.jpg", alt: "What it shows", at: "top" },
    { type: "youtube", id: "V6VsxcVpBVY", title: "Video title", credit: "Channel name", at: "end" }
  ],
  reflect: { q: "Question for the reader", a: "Possible answer" },
  refs: ["refKey"]
}
```

## 3. All media types (copy and paste)

**Image**
```js
{ type: "image", src: "images/file.jpg", alt: "Describe the image", caption: "Optional", credit: "Source", at: "top" }
```

**YouTube** (the id is the part after `v=` in the link). The player only loads when clicked, so the page stays fast. Add `start: 90` to start at 1:30.
```js
{ type: "youtube", id: "VIDEO_ID", title: "Title", credit: "Channel", at: "end" }
```

**Your own video file** (keep it under about 5 MB, MP4, 720p, in `/video`)
```js
{ type: "video", src: "video/clip.mp4", poster: "images/poster.jpg", caption: "...", transcript: "..." }
```

**Audio** (MP3, small, in `/audio`; always add a transcript)
```js
{ type: "audio", src: "audio/defcon.mp3", title: "Listen", credit: "Source", transcript: "What is heard..." }
```

**Compare** (two columns; tones: `"a"`, `"b"`, `"good"`, `"bad"`)
```js
{ type: "compare", at: "hook",
  left:  { title: "Left title",  tone: "good", items: ["point", "point"] },
  right: { title: "Right title", tone: "bad",  items: ["point", "point"] } }
```

**Gallery**
```js
{ type: "gallery", items: [ { src: "images/a.jpg", caption: "A" }, { src: "images/b.jpg", caption: "B" } ] }
```

**Dilemma** (interactive choices, see Q5 node 5.3)
```js
{ type: "dilemma", title: "What would you do?", scenario: "...",
  choices: [ { label: "Option A", outcome: "...", lenses: [ { name: "Kant", text: "..." } ] } ] }
```

**Chart with a year slider** (Q5 "macro data" node). **Use only real, cited numbers.** It stays hidden until `years` and both `values` lists are filled and the same length.
```js
{ type: "chart", title: "...", years: [1995, 2000, 2005],
  series: [ { name: "Game sales", values: [..] }, { name: "Youth violent crime", values: [..] } ],
  source: "ESA (year); OJJDP (year)" }
```

**Embed** (e.g. a Flourish/Canva chart share link)
```js
{ type: "embed", src: "https://...", title: "...", ratio: "16/9" }
```

**Slot** (a to-do note, only visible in `?dev`). Replace it with a real item when it's done.
```js
{ type: "slot", kind: "video", brief: "What is needed", tips: "How to find it" }
```

## 4. Node card images

The small picture on a card on the map is the node's `img:` field (not `detail.media`):
```js
{ id: "hub", ..., img: "images/what-is-metaverse.jpeg", ... }
```
Expected files in `images/`: `secondlife_main.png`, `secondlife.jpg`, `disinhibition.jpg`, `what-is-metaverse.jpeg`, `metaverse.jpg`, `metaverse2.jpg`, `Digital_id.jpeg`, `Digital_id2.jpg`, `metaverseNethics2.jpg`. **File names are case-sensitive once online.**

## 5. Sounds

- The built-in interface sounds are generated by the browser, so there are no files and no licences.
- To use your own sounds, put small files (under 50 KB) in `/audio` and set them in `js/data/config.js` → `sounds: { open: "audio/open.mp3" }`.
- Only use royalty-free or Creative Commons sounds (Pixabay, Freesound CC0) and cite them.

## 6. Rules (it's an IP-ethics assignment, so practise it)

- **Embed** YouTube videos. Don't download and re-upload them.
- **Cite every video** in the branch's `refs` (Harvard format: Channel (year) *Title* [YouTube video]. Available at: URL (Accessed: date)).
- Keep images under about 300 KB (compress at squoosh.app).
- Add `alt` text to images and transcripts to audio.
- Test the final version from the **hosted link**. YouTube embeds can fail when the file is opened straight from a folder.
